# Changelog

## 1.0.0 - 2026-08-26

- Replaced the React/Vite prototype with a Flutter Android, iOS, and web app.
- Ported all eight local game families and migrated/validated their source prompt banks.
- Added native same-Wi-Fi hosting, WSS fingerprint pinning, NSD/Bonjour discovery, QR/manual joins, revisioned authority, recipient projections, voting, and reconnect behavior.
- Corrected Solo Timer persistence, routes, onboarding, source counts, permissions, and privacy copy.
- Added custom offline web caching, GitHub Pages deployment, multi-platform CI, tests, store assets, and release documentation.
- Added the saturated full-bleed party visual system, bundled Fredoka typography, game/state palettes, sticker components, tactile motion, responsive prompt type, and visual golden coverage.
- Rebuilt Imposter with Classic and Odd Word modes, optional hints, local and Nearby voting, multi-round elimination, curated related-word groups, private recipient projections, and full-name player badges.
- Upgraded Nearby commands to protocol v2 with authenticated sender binding, addressed host messages, private ballots, and 60-second player/host reconnect handling.
